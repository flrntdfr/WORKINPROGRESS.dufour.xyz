🎵 Apple Music User Token

One-time setup to authorize access to your Apple Music library

📋 Before you start:

  1. Generate your Developer Token using npm run generate-token
  2. Paste the Developer Token below
  3. Click "Authorize" to sign in with your Apple ID
  4. Copy the User Token and add it to your .envrc file

💡 Debugging: Open Browser Console (F12 or Cmd+Option+I) to see detailed error logs if authorization fails.
